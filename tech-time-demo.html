🔄 Drag-and-Drop Reordering

Each task now has a drag handle (⋮⋮) that allows reordering within the same list section.

How It Works
  1. Grab the ⋮⋮ handle
  2. Drag to new position
  3. Drop in place
  4. Order auto-saves to HA
Features
  • Visual feedback during drag
  • Persists across sessions
  • Works on all devices
  • Within-list only (safe)

🚀 Getting Started

Step 1: Update Config
Add enable_tech_time_notifications: true to each child's config in your dashboard YAML.
Step 2: Mark Tasks
Use the Parent Console to check "⚡ Required for tech time" when adding or editing tasks.
Step 3: Test It Out
Complete all tech-time tasks for a child and watch for the notification prompt!

📋 Data Storage

Tech-time and order metadata are stored in each task's description field as JSON:

{
"tech_time": true,
"order": 2
}

This approach works with standard Home Assistant todo entities without requiring custom fields.
